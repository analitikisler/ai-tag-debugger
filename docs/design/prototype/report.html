  • purchase was sent without currency, value.

    GA4purchaseDeveloper1 journey · 1 step     Broken

    Illustrative AI text: this run had AI off. The anatomy below is what a run with a provider shows.

    ImpactGA4 records the order but with no revenue: purchase conversions, ROAS and the ecommerce reports show 0 for every mobile order until this is fixed.
    Likely cause

    The mobile checkout pushes purchase with transaction_id and items but without the top-level ecommerce.currency and ecommerce.value. The desktop template sends both, so the two checkout templates have diverged.

    Evidence

    3. Place a test order on a phone and check GA4 DebugView: purchase must show value and currency.
